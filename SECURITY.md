# Security Policy

## Supported versions

Trajan has no release yet. Once it ships, the latest release is the supported one.

Until the engine moves here, the desktop app's code lives in Flavian's `packages/gui`. Report a
problem in that code through [Flavian's security policy](https://github.com/PMDevSolutions/Flavian/security/policy).

## Reporting a vulnerability

Please do not open a public issue for a security vulnerability.

Use **Report a vulnerability** on this repository's
[Security tab](https://github.com/PMDevSolutions/Trajan/security/advisories/new). The report stays
private between you and the maintainer.

### What to include

- A description of the vulnerability
- Steps to reproduce it
- The potential impact
- A suggested fix, if you have one

### Response timeline

- Acknowledgment: within 48 hours
- Initial assessment: within 1 week
- Fix or mitigation: as soon as reasonably possible
